# **App Name**: ALEXIS Atelier

## Core Features:

- Full-Screen Immersive Hero: Display a full-screen, immersive video background with central navigation (Catalog, AI Advisor, Process, Booking) and floating elements like the brand's establishment year and tagline on the home page.
- The Collection Gallery: Showcase the collection in a gallery grid format, highlighting different looks like Double Breasted, Fabric Detail, Casual Rebel, and Music x Tailoring.
- AI Look Decoder: Implement a feature where users can click on an image in the catalog, triggering Gemini AI to analyze the style and provide insights.
- AI Style Advisor: Develop a terminal-style interface where users input an occasion/mood (e.g., "ex-girlfriend's wedding"), and AI generates a style protocol as outfit recommendations.
- The Process Visualization: Illustrate the bespoke tailoring process in a step-by-step manner: Consultation, Measurement, Fitting.
- Booking System with Firestore Integration: Create a booking form to collect client name, contact number, date, style preference, and notes, and store the booking information in Firestore, also enable anonymous login.
- AI Note Refinement Tool: Integrate an AI-powered tool within the booking form that allows users to refine their notes for clarity and impact before submitting.

## Style Guidelines:

- Primary color: Deep Charcoal (#333333), reminiscent of tailored suits and classic sophistication.
- Background color: Off-White (#F0F0F0), a slightly desaturated and bright tone for contrast.
- Accent color: Muted Gold (#B8860B), analogous to deep charcoal yet with a striking difference in brightness and saturation for highlighting key elements.
- Headline font: 'Playfair', a modern sans-serif font for an elegant, high-end feel; body text: 'PT Sans' (sans-serif) for body, providing great readability and modern flair.
- Use minimalist line icons for navigation and process steps.
- Adopt a multi-page application structure for better navigation and content organization, breaking away from the single-page design.
- Implement subtle transitions and animations for a refined user experience.
